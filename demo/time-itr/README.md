# TIME-ITR — Time Management App

Aplikasi demo front-end berbasis HTML, CSS, Bootstrap 5, JavaScript, Chart.js, dan LocalStorage.

## Mulai
Buka `index.html` di browser dengan koneksi internet (Bootstrap, ikon, font, Chart.js memakai CDN). Untuk pengembangan gunakan Live Server.

## Fitur
- Dual theme dark/light (tersimpan di LocalStorage)
- Dashboard ringkasan tugas
- CRUD tugas, prioritas, tenggat, checklist, filter
- Weekly Planner berdasarkan tenggat tugas
- Timer Pomodoro 25 menit, istirahat 5/15 menit
- Analitik status tugas dan catatan sesi fokus
- Responsive mobile
- Ilustrasi cover 4K 3840×2160 di `assets/images/cover-4k.png`

## Penting
Data hanya di browser/perangkat yang sama; bukan cloud sync. Timer dapat berhenti/tertunda bila tab ditutup atau dibatasi browser. Tidak ada autentikasi maupun notifikasi push. Ilustrasi 4K adalah aset grafis, bukan resolusi tampilan antarmuka.
