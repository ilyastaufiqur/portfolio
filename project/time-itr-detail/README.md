# TIME-ITR — Halaman Detail Project

Template mandiri untuk menampilkan detail aplikasi TIME-ITR di website portofolio Ilyas.

## Memasang
1. Salin folder ini sebagai `projects/time-itr/` di PORTFOLIO-ILYAS.
2. Pada kartu project di `index.html` portofolio, arahkan `href="projects/time-itr/index.html"`.
3. Tombol Live Demo sudah diarahkan ke `../../demo/TIME-ITR/index.html` dan tombol kembali ke `../../index.html#projects`, sesuai lokasi `projects/time-itr/`.
4. Ganti `href="#"` tombol Source Code dengan URL GitHub milikmu.
5. Ganti ilustrasi SVG di `assets/images/` dengan screenshot asli dan sesuaikan `src` di HTML.
6. Buka `index.html` untuk melihat hasil. Bootstrap & ikon memakai CDN (butuh internet).

## Catatan
- Semua deskripsi berbahasa Indonesia.
- Ilustrasi SVG berukuran intrinsik 3840×2160 (4K), tetapi bukan screenshot nyata.
- Sesuaikan klaim fitur dengan implementasi TIME-ITR yang benar-benar tersedia.
- Demo aplikasi tidak disertakan dalam paket ini; ini khusus halaman detail project.
