# PEJUANGMUDA-LOG — Detail Proyek

Template halaman detail proyek dalam bahasa Indonesia.

## Memasang ke PORTFOLIO-ILYAS
1. Salin folder ini ke `PORTFOLIO-ILYAS/projects/pejuangmuda-log/`.
2. Salin aplikasi demo asli ke `PORTFOLIO-ILYAS/demo/PEJUANGMUDA-LOG/`.
3. Tautkan kartu proyek di halaman portofolio ke `projects/pejuangmuda-log/index.html`.
4. Tombol Live Demo sudah menggunakan path relatif `../../demo/PEJUANGMUDA-LOG/index.html`. Sesuaikan jika nama folder berbeda.
5. Ganti link GitHub (`https://github.com/`) dengan URL repository milikmu.
6. Ganti semua gambar SVG ilustrasi dengan screenshot aplikasi asli (atau perbarui atribut src).
7. Sesuaikan fitur/teknologi/tantangan agar sesuai implementasi nyata.

## Catatan
Ini hanya halaman detail portofolio, bukan aplikasi logbook. Bootstrap dan font dimuat melalui CDN, sehingga memerlukan koneksi internet untuk tampil sempurna. Proyek independen, bukan aplikasi resmi Kemensos RI.
