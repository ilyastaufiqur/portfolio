# KAS-ITR — Project Details

Halaman detail portofolio KAS-ITR, berbahasa Indonesia, responsif, dual theme.

## Struktur penempatan yang disarankan

```text
PORTFOLIO-ILYAS/
├── index.html
├── projects/
│   └── kas-itr/
│       ├── index.html
│       └── assets/
└── demo/
    └── KAS-ITR/
        ├── index.html
        └── assets/
```

Salin **isi ZIP ini** ke `projects/kas-itr/`. Salin **isi ZIP aplikasi KAS-ITR** ke `demo/KAS-ITR/`.

Tombol Live Demo menggunakan path relatif `../../demo/KAS-ITR/index.html`.

Tombol kembali portofolio mengarah ke `../../index.html#projects`.

Untuk menambahkan GitHub, isi konstanta `GITHUB_URL` pada `assets/js/main.js`. Jika belum diisi, tombol menampilkan petunjuk.

Galeri berisi ilustrasi SVG buatan untuk presentasi, **bukan screenshot aplikasi asli**. Kamu boleh menggantinya dengan screenshot milikmu sendiri.

Bootstrap dimuat dari CDN, dan Google Fonts memerlukan internet. HTML, CSS, dan JS halaman detail dapat diedit bebas.
